# Example LaTeX Paper Project

## Project Summary
- Minimal example of a LaTeX paper with linked analysis and optional slides.

## Paper Conventions
- Main manuscript path: `paper/main.tex`
- Manuscript format: `latex`
- Bibliography path: `paper/references.bib`

## Analysis Conventions
- Main code root: `analysis/`
- Preferred entrypoint scripts: `analysis/run.R`

## Working Norms
- Save review outputs to `workflow/reports/`.
